파일 읽기
1. git clone "깃주소"
2. branch 변경
   git checkout branch명
   git branch -a  => 브런치 목록 확인
3. 최신 데이터 읽기
   git pull origin branch명
4. git fetch origin branch명 => 원격으로 변경사항 읽기
5. git merge origin/main => 브런치 병합
6. 충돌 된 경우
   git add .
   git commit -m "commit다른명"
   git push origin branch명
7. pull 안될때
   git pull --rebase
